# Píldora formativa: Machine Learning

## Underfitting, Optimal Fit, Overfitting & Regularization

### About this project

This repository contains an academic presentation about fundamental Machine Learning concepts, focusing on how models learn from data, how their performance is evaluated, and how to prevent underfitting and overfitting.

The presentation introduces three important learning outcomes — Underfitting, Optimal Fit and Overfitting — and explores Regularization as a technique to control model complexity.

The material is designed as an introductory educational resource, supported by diagrams, examples and Python / Scikit-learn demonstrations.

## Learning objectives

- Understand the basic principles of Machine Learning and supervised learning.
- Distinguish between Training and Testing datasets.
- Understand how a model is trained and makes predictions.
- Learn how MAE (Mean Absolute Error) measures prediction errors.
- Identify Underfitting, Optimal Fit and Overfitting.
- Understand the importance of generalization to unseen data.
- Explore Regularization as a technique to control model complexity.
- Introduce Polynomial Regression and compare different polynomial degrees.
- Understand the role of Ridge Regression in regularization.

## Topics covered

1. Introduction to Machine Learning.
2. Supervised Learning: Training and Testing.
3. Model training and prediction with Python and Scikit-learn.
4. Measuring prediction errors with MAE.
5. Underfitting, Optimal Fit and Overfitting.
6. Regularization.
7. Polynomial Regression: degrees 1, 2 and 12.
8. Ridge Regression and model complexity.
9. Interpretation of results and conclusions.

## Intended audience

Students and learners with basic or intermediate computer knowledge who want an introduction to Machine Learning concepts.

## Project purpose

This project was developed as an academic presentation to explain how Machine Learning models learn from examples, how their performance can be evaluated, and why finding an appropriate balance between model simplicity and complexity is essential.

**Key idea:** The goal is to learn patterns that generalize to new data, not simply memorize training examples.
